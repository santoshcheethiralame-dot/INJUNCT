How this works

Injunct reads the documents your agents are given and finds every sentence that sounds like an instruction. A model (gemma-4-26b-a4b-it) sorts each one: either it can be written as one of six simple checks on a commit, or it cannot, and it says why. Then each check is replayed against this repository's own past commits. A check that every past commit already followed is guarded: it can stop an agent without ever blocking work that already shipped. Nothing the model wrote is ever run.
