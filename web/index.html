Injunct

A coding agent forgets a lesson the moment the conversation ends. This turns a confirmed failure into a check that blocks the next change repeating it — deterministic, executable, and cited to the run that established it. Before any rule is allowed to refuse anything, it is replayed against this repository's own history: it must catch its own case, and stay silent on work that already succeeded.

The docket Every rule on file, in drawers by authority. Open one to see the case behind it, the receipt that earned it the right to block, and every time it has been cited since. The evidence Does it help, and where does it hurt — including the compliance zone where the tool makes an agent worse than no memory at all. The tape Three hundred runs replayed in about three seconds, arm A against arm C, in the order they actually ran. The desk Every rule's decision as a change lands. Live while injunct watch runs; otherwise a real recorded session, labelled as a replay. Overruled How a rule loses its authority. Three runs that overrode it and succeeded anyway, and it retires itself in public.
The race is not here. It runs two copies of one app side by side and needs a server behind it, so it lives at python -m injunct demo on port 8900 rather than on this static site.
